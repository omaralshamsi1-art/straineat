        WHOOP —
        Apple Health —

        الموقع لا يستطيع قراءة Apple Health مباشرة، لذلك نستخدم اختصار آيفون يرسل حرقك تلقائياً عدة مرات في اليوم.

        خطوات إعداد الاختصار (مرة واحدة)
        1. افتح تطبيق الاختصارات (Shortcuts) ← + وسمّه StrainEat.
        2. أضف Find Health Samples (البحث عن عينات الصحة): النوع Active Energy (الطاقة النشطة)، وأضف شرط Start Date ← is today.
        3. أضف Calculate Statistics (حساب الإحصائيات) ← Sum، ثم Set Variable باسم active.
        4. كرر الخطوتين 2 و3 مع Resting Energy (طاقة الراحة) واسم المتغير basal.
        5. أضف Get Contents of URL والصق الرابط المنسوخ ← Method: POST ← Request Body: JSON وأضف حقلين رقميين: active = المتغير active، وbasal = المتغير basal.
        6. شغّل الاختصار مرة واسمح بالوصول لبيانات الصحة، ثم اضغط «تحقق من وصول البيانات».
        7. من تبويب Automation (الأتمتة) ← + ← Time of Day: الساعة 12:00 يومياً ← Run Immediately ← اختر الاختصار. كرر للساعة 6 و10 مساءً.
